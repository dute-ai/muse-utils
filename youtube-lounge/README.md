# youtube-lounge

Control YouTube playback on your TV from a chat message — play, pause,
resume, stop, and check what's playing — using YouTube's unofficial
**Link with TV code** protocol. Commands go through YouTube's cloud, so
the TV doesn't need to be on the same network. (The YouTube app must
already be open on the TV.)

Part of the [muse-utils](https://github.com/dute-ai/muse-utils) collection.

## Use it

Paste into Muse:

> Install the youtube-lounge skill from
> https://github.com/dute-ai/muse-utils: clone it to ~/workspace/muse-utils
> and run install.sh. Then pair my TV — I'll give you the 12-digit code
> from the TV's YouTube app → Settings → Link with TV code.

After that, just ask:

- "Play <video> on the living room TV."
- "Pause the TV." / "What's playing on the TV?"
